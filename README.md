# CRM-система для управления продажами

Веб-приложение для автоматизации процессов продаж, учета клиентов и сделок, повышения эффективности работы менеджеров по продажам.

## Описание проекта

CRM-система представляет собой полнофункциональное веб-приложение, разработанное в рамках выпускной квалификационной работы студента Дагестанского государственного университета народного хозяйства по специальности "Информационные системы и программирование".

## Технологии

- **Backend:** PHP 7.4+ (процедурный подход)
- **База данных:** MySQL 5.7+
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Фреймворки и библиотеки:**
  - Bootstrap 5.3.0
  - Font Awesome 6.4.0

## Функциональные возможности

### Модуль авторизации
- Вход в систему (логин/пароль)
- Выход из системы
- Разграничение прав доступа (Администратор, Менеджер)

### Модуль управления клиентами
- Добавление нового клиента (ФИО, телефон, email, компания)
- Просмотр списка клиентов
- Редактирование данных клиента
- Удаление клиента
- Поиск клиента по имени/телефону/компании

### Модуль управления сделками
- Создание новой сделки (клиент, сумма, описание)
- Просмотр списка сделок
- Изменение статуса сделки (Новая, В работе, Успешно завершена, Отменена)
- Редактирование сделки
- Удаление сделки
- Фильтрация по статусу
- Привязка сделки к клиенту и менеджеру

### Модуль задач
- Создание задачи (описание, срок, ответственный менеджер)
- Просмотр списка задач
- Отметка о выполнении задачи
- Удаление задачи
- Фильтрация по статусу (активные/выполненные)

### Модуль отчетности
- Общая статистика (количество клиентов, сделок, общая сумма продаж)
- Отчет по менеджерам (количество сделок, сумма продаж)
- Воронка продаж (количество сделок по статусам)
- Топ клиентов по сумме сделок
- Фильтрация по периоду (за месяц, квартал, год)

### Личный кабинет
- Просмотр профиля пользователя
- Редактирование данных профиля (ФИО, email)
- Смена пароля

## Установка и настройка

### Требования

- PHP 7.4 или выше
- MySQL 5.7 или выше
- Apache/Nginx веб-сервер
- Поддержка модуля mod_rewrite (для Apache)

### Быстрая установка для Ampps (Windows)

**Рекомендуется для студентов и быстрого запуска проекта**

#### 1. Размещение файлов

Скопируйте содержимое проекта в директорию Ampps:
```
D:\prog\Ampps\www\CRM-Sale\
```

#### 2. Настройка базы данных

**Вариант A - Через phpMyAdmin (рекомендуется):**

1. Откройте phpMyAdmin: `http://localhost/phpmyadmin`
2. Нажмите "Новая" в левом меню
3. Введите имя базы данных: `crm_sales`
4. Кодировка: `utf8mb4_unicode_ci`
5. Нажмите "Создать"
6. Перейдите во вкладку "SQL"
7. Скопируйте весь текст из файла `database/schema.sql` и выполните
8. Затем скопируйте текст из `database/test_data.sql` и выполните

**Вариант B - Через командную строку:**

```cmd
cd D:\prog\Ampps\mysql\bin
mysql.exe -u root -pmysql < D:\prog\Ampps\www\CRM-Sale\database\schema.sql
mysql.exe -u root -pmysql < D:\prog\Ampps\www\CRM-Sale\database\test_data.sql
```

#### 3. Настройка конфигурации

Скопируйте файл примера и настройте подключение:

1. Скопируйте `config/database.php.example` в `config/database.php`
2. Откройте `config/database.php` в текстовом редакторе
3. Убедитесь, что параметры такие:

```php
define('DB_HOST', 'localhost');
define('DB_USER', 'root');
define('DB_PASS', 'mysql');        // Пароль по умолчанию в Ampps
define('DB_NAME', 'crm_sales');
```

#### 4. Запуск

1. Убедитесь, что Apache и MySQL запущены в Ampps
2. Откройте браузер
3. Перейдите по адресу: `http://localhost/CRM-Sale`

#### 5. Вход в систему

Используйте тестовый аккаунт администратора:
- **Логин:** admin
- **Пароль:** password123

**Готово!** Система установлена и готова к работе.

### Пошаговая инструкция (Linux/macOS)

#### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd CRM-Sales
```

#### 2. Настройка базы данных

**Шаг 1:** Создайте базу данных MySQL:

```bash
mysql -u root -p
```

**Шаг 2:** Выполните SQL скрипт для создания структуры БД:

```bash
mysql -u root -p < database/schema.sql
```

**Шаг 3:** (Опционально) Загрузите тестовые данные:

```bash
mysql -u root -p < database/test_data.sql
```

#### 3. Настройка подключения к базе данных

Отредактируйте файл `config/database.php`:

```php
define('DB_HOST', 'localhost');     // Хост базы данных
define('DB_USER', 'root');          // Пользователь БД
define('DB_PASS', '');              // Пароль БД
define('DB_NAME', 'crm_sales');     // Название БД
```

#### 4. Настройка веб-сервера

**Для Apache:**

Убедитесь, что DocumentRoot указывает на директорию проекта.

Пример конфигурации виртуального хоста:

```apache
<VirtualHost *:80>
    ServerName crm-sales.local
    DocumentRoot /path/to/CRM-Sales

    <Directory /path/to/CRM-Sales>
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>
```

**Для Nginx:**

```nginx
server {
    listen 80;
    server_name crm-sales.local;
    root /path/to/CRM-Sales;
    index index.php index.html;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php7.4-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }
}
```

#### 5. Права доступа

Установите корректные права доступа к файлам:

```bash
chmod -R 755 /path/to/CRM-Sales
```

#### 6. Запуск приложения

Откройте браузер и перейдите по адресу:

```
http://localhost/CRM-Sales
```

или

```
http://crm-sales.local
```

## Безопасность

Система включает следующие меры безопасности:

- Хеширование паролей с использованием `password_hash()`
- Защита от SQL-инъекций через prepared statements
- Проверка авторизации на всех страницах
- Валидация пользовательского ввода
- Экранирование HTML-символов
- Защита от XSS-атак
